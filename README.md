# 🚀 AutoInstall

**Быстрая установка программ на Windows через WinGet** — один скрипт, все нужные программы.

## ✨ Возможности

- **Единый экран выбора** — все программы на одном экране с категориями
- **Мульти-выбор** — вводите номера через пробел (`1 3 5 7`)
- **Выбрать всё** — одна клавиша `A`
- **Переключение** — повторный ввод номера снимает выбор
- **Прогресс** — счётчик `[2/5]` при установке
- **Отчёт** — итоговая таблица с результатами (✓ / ✗)

## 📋 Требования

- Windows 10 (1709+) / Windows 11
- [WinGet](https://aka.ms/getwinget) (предустановлен в Windows 11)

## 🔧 Использование

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/Refyrd/AutoInstall.git
   ```
2. Запустите `setup.bat` (автоматически запросит права администратора)
3. Выберите нужные программы
4. Нажмите `D` для начала установки

## ⌨️ Управление

| Клавиша | Действие |
|---------|----------|
| `1-9` | Выбрать/снять программу |
| `1 3 5` | Выбрать несколько сразу |
| `A` | Выбрать все |
| `C` | Сбросить выбор |
| `D` | Начать установку |
| `0` | Выход |
